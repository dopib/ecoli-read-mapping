# Картирование ридов E. coli

Учебный проект: картирование полного файла `ERR022075_1.fastq.gz` на геном
E. coli K-12 MG1655 (`GCF_000005845.2_ASM584v2`, 4 641 652 п. н.).

Для картирования используется Bowtie 2. Собственный код на Python читает FASTQ,
проверяет записи и по выводу SAM считает долю картированных ридов, неоднозначные
совпадения, качество выравнивания и покрытие генома.

## Как работает решение

1. Bowtie 2 строит FM-индекс референса на основе преобразования Барроуза — Уилера.
2. Для каждого рида ищет короткие участки совпадения на обеих цепях и расширяет
   их динамическим программированием с учётом замен, вставок и удалений.
3. Режим `--very-sensitive-local` допускает обрезку плохо совпадающих концов.
   Параметр `-k 2` позволяет найти до двух допустимых положений одного рида.
4. Python обрабатывает SAM построчно. Для качества и покрытия учитывается одно
   основное выравнивание на рид. Дополнительное нужно только для подсчёта
   multi-mapped ридов.
5. Покрытие считается через массив разностей: начало блока прибавляет 1,
   конец вычитает 1, затем накопленная сумма даёт глубину в каждой позиции.

Готовый Bowtie 2 здесь используется как внешний инструмент, а не выдаётся за
собственную реализацию. В задании разрешено использовать любые алгоритмы.
Это позволяет оставить решение небольшим и обработать весь набор данных.

## Запуск в Linux / WSL

Нужны Python 3.10+, NumPy и Bowtie 2. Для повторения измерений использованы
Python 3.10, NumPy 2.2.6 и Bowtie 2.5.5.

```bash
# Например, установка Bowtie 2 через conda:
conda install -c conda-forge -c bioconda bowtie2=2.5.5
python -m pip install -r requirements.txt

# Загрузка референса и ридов:
python src/download_data.py
bowtie2-build data/reference.fna data/ecoli_index

# Полное картирование и расчёт статистики:
python src/map_reads.py --reads data/ERR022075_1.fastq.gz \
    --reference data/reference.fna --index data/ecoli_index \
    --threads 8 --output results

python src/verify_results.py
python src/write_report.py
python -m unittest discover -s tests -v
```

Если FASTQ уже скачан, достаточно `python src/download_data.py --reference-only`,
а в `--reads` нужно передать путь к своему файлу. Распаковывать FASTQ не требуется.

## Запуск в Windows

Можно скачать [официальную сборку Bowtie 2.5.5 для Windows](https://github.com/BenLangmead/bowtie2/releases/download/v2.5.5/bowtie2-2.5.5-mingw-x86_64.zip)
и распаковать её в папку `tools`. Вместо оболочки `bowtie2` используется
исполняемый файл `bowtie2-align-s.exe`, а для индекса — `bowtie2-build-s.exe`:

```powershell
python -m pip install -r requirements.txt
python src/download_data.py --reference-only
& ./tools/bowtie2-2.5.5-mingw-x86_64/bowtie2-build-s.exe data/reference.fna data/ecoli_index
python src/map_reads.py --reads "D:/path/to/ERR022075_1.fastq.gz" --reference data/reference.fna --index data/ecoli_index --aligner ./tools/bowtie2-2.5.5-mingw-x86_64/bowtie2-align-s.exe --threads 8 --output results
python src/verify_results.py
python src/write_report.py
```

Каждый запуск перезаписывает результаты в указанной папке. `write_report.py`
и `verify_results.py` работают с папкой `results` в корне репозитория.
Исходные FASTQ, референс и индекс в GitHub не загружаются.

## Что важно при интерпретации

При запуске также сохраняется локальный `results/alignment_sample.sam` с первыми
1 000 ридами из вывода. Он исключён из GitHub вместе с исходными последовательностями.

«Unique» означает, что найдено одно допустимое положение; «multi-mapped» — два.
Поиск эвристический, поэтому отсутствие второго совпадения не доказывает строгую
уникальность. Второе совпадение не обязано иметь такой же балл, как первое.

Локальное выравнивание может отбросить часть рида, поэтому высокая доля
картирования показана вместе с долей сохранённых оснований. Качество оценивается
по идентичности и числу ошибок; MAPQ в режиме `-k` не интерпретируется как
надёжная оценка уверенности. Точные определения приведены в отчёте.

Обработан только указанный в задании файл первого mate, как single-end набор.
Дубликаты не удаляются, фильтрация по качеству не применяется. Референс линейный,
поэтому переход через границу кольцевой хромосомы специально не обрабатывается.

Структура короткого отчёта ориентируется на [предоставленный образец](https://github.com/iaraha/Genome-mapping).
Код и результаты образца не использовались. Описание параметров:
[руководство Bowtie 2](https://bowtie-bio.sourceforge.net/bowtie2/manual.shtml).
